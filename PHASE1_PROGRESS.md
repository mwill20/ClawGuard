
## ClawGuard Telemetry Hook

Post-compile hook:

```text
target-agent/skills/job-search-custom/clawguard_post_compile.sh
```

Deployed VPS path:

```text
/docker/openclaw-utxu/data/clawguard/clawguard_post_compile.sh
```

Telemetry output path inside the OpenClaw data volume:

```text
/data/clawguard/telemetry/
```

The hook writes:

```text
telemetry_<date>_<agent_session_id>.json
telemetry_<date>_<agent_session_id>.md
telemetry_latest.json
telemetry_latest.md
```

`telemetry_latest.*` writes are atomic: content is written to a same-directory PID-scoped temp file and swapped into place with `os.replace()`.

## Quick Commands

Check cron logs on the VPS:

```bash
tail -80 /docker/openclaw-utxu/data/clawguard/logs/cron.log
```

View latest telemetry after the 9:30 AM PT compile:

```bash
cat /docker/openclaw-utxu/data/clawguard/telemetry/telemetry_latest.md
```

Run the zero-UI findings query:

```bash
docker exec -i openclaw-utxu-openclaw-1 sqlite3 /data/clawguard/jobs.db <<'SQL'
SELECT
  agent_session_id,
  rule_id,
  severity,
  json_extract(context, '$.source_platform') AS source_platform,
  json_extract(context, '$.source_field') AS source_field,
  detected_at
FROM job_security_findings
ORDER BY detected_at DESC
LIMIT 20;
SQL
```

Compile current-day digest manually without preparing applications:

```bash
docker exec \
  -e CLAWGUARD_DATA_DIR=/data/clawguard \
  -e CLAWGUARD_ENRICHMENT_DAILY_CAP=0 \
  -w /usr/local/lib/node_modules/openclaw/skills/job-search-custom \
  openclaw-utxu-openclaw-1 \
  python3 -B job_search_secure.py digest --compile --no-prepare --no-notify --format json
```

Export latest telemetry to the repo workspace:

```powershell
.\scripts\export_latest_telemetry.ps1
```
