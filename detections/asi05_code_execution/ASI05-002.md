# ASI05-002 - Unapproved Container Action

## Summary

Flags `container_action` runtime events whose container label or operation is
outside the approved cron/deploy inventory.

## Evidence

- `event_id`
- container label
- operation label
- approved container labels and operations
- `container_id_stored: false`
- `remote_host_stored: false`

## Non-Goals

- Do not alert on approved cron wrapper container actions.
- Do not persist container IDs or host identifiers.
- Do not block runtime behavior in v1.
