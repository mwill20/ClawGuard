# ASI05-001 - Unapproved Process Label

## Summary

Flags `process_exec` runtime events whose command label or operation is outside
the approved validation/cron inventory.

## Evidence

- `event_id`
- process label
- operation label
- approved process label inventory
- `raw_command_stored: false`

## Non-Goals

- Do not alert on approved cron wrapper runs.
- Do not store raw command lines or arguments.
- Do not duplicate ASI02 job-content shell payload detection.
