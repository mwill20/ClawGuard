# ASI03-002 - Credential Egress Mismatch

## Summary

Flags sessions where an unapproved credential label appears with network egress
to a non-approved destination domain.

## Evidence

- credential event ID
- egress event ID
- credential label
- destination domain label
- approved egress domains

## Non-Goals

- Do not alert on Brave or USAJobs provider egress.
- Do not store request bodies.
- Do not persist raw secrets or host identifiers.
