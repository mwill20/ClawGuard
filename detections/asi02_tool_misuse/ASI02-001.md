# ASI02-001: Unsafe HTTP Egress Redirect

Status: Implemented in `detections/asi02_tool_misuse/detector.py`
Rule ID: ASI02-001
Runtime rule: `ASI02_EGRESS_REDIRECT`
Severity: HIGH

Detects untrusted job content that instructs the agent to fetch, post, upload,
or beacon to a URL outside the configured safe egress domains.

Safe domains are intentionally narrow in v1: Brave Search API, USAJobs API,
LinkedIn, USAJobs, and CyberSecJobs.
