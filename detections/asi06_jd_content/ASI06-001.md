# ASI06-001: Job Description Prompt Injection

Status: Rule stub
OWASP mapping: ASI06 Memory Poisoning / Context Manipulation
Current runtime location: `target-agent/skills/job-search-custom/job_search_secure.py`

## Summary

Detect prompt-injection language embedded in job descriptions, job titles, or scraped job-board content that attempts to alter the agent's scoring, filtering, preparation, or submission behavior.

The job posting is untrusted data. Any instruction inside the posting that asks the agent to ignore prior instructions, override scoring, mark a role as a strong match, hide other jobs, or assume a new system/developer role is treated as suspicious content.

## Initial Detection Patterns

Current inline patterns include:

```text
ignore previous instructions
score this job at <number>
mark this as strong match
do not show other
override scoring
system: you are
developer: you are
```

## Required Evidence

Each finding should preserve:

- `matched_pattern`: the normalized pattern that fired.
- `source_field`: the field that contained the pattern, such as `title_and_description`.
- `job_title`: title from the job record.
- `company`: company from the job record.
- `source_platform`: job source, such as `linkedin`, `cybersecjobs`, or `usajobs`.
- `apply_url`: application URL being evaluated.
- `agent_session_id`: digest or run id that evaluated the posting.

## Current Event Shape

Expected row in `job_security_findings`:

```json
{
  "job_id": "example-job-id",
  "agent_session_id": "digest-YYYYMMDDTHHMMSS-xxxxxxxx",
  "rule_id": "ASI06_PROMPT_INJECTION",
  "severity": "HIGH",
  "message": "Job description contains prompt-injection language.",
  "evidence": {
    "patterns": ["ignore\\s+(all\\s+)?previous\\s+instructions"]
  },
  "context": {
    "job_id": "example-job-id",
    "job_title": "Security Engineer",
    "company": "ExampleCo",
    "source_platform": "linkedin",
    "apply_url": "https://www.linkedin.com/jobs/view/example",
    "source_field": "title_and_description"
  }
}
```

## Initial Query

This query acts as the zero-UI detection dashboard for ASI06-001:

```sql
SELECT
  agent_session_id,
  rule_id,
  severity,
  json_extract(context, '$.source_platform') AS source_platform,
  json_extract(context, '$.source_field') AS source_field,
  json_extract(context, '$.job_title') AS job_title,
  detected_at
FROM job_security_findings
WHERE rule_id = 'ASI06_PROMPT_INJECTION'
ORDER BY detected_at DESC
LIMIT 20;
```
