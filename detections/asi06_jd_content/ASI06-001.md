# ASI06-001: Adversarial Prompt Injection via Job Description Ingestion

Status: Rule stub
Rule ID: ASI06-001
Name: Adversarial Prompt Injection via Job Description Ingestion
OWASP mapping: ASI06 - Memory Poisoning / Context Manipulation
Severity: HIGH
Detection layer: Layer 1 Regex now, Layer 4 LLM semantic fallback planned
Current runtime location: `target-agent/skills/job-search-custom/job_search_secure.py`

## Summary

Detect prompt-injection language embedded in job descriptions, job titles, or scraped job-board content that attempts to alter the agent's scoring, filtering, preparation, or submission behavior.

The job posting is untrusted data. Any instruction inside the posting that asks the agent to ignore prior instructions, override scoring, mark a role as a strong match, hide other jobs, or assume a new system/developer role is treated as suspicious content.

## Trigger Condition

Trigger when job-posting content contains patterns consistent with prompt injection targeting an LLM or downstream agent that processes the posting.

Primary trigger:

- Layer 1 regex match against known prompt-injection language.

Future trigger:

- Layer 4 semantic fallback when suspicious text is not covered by known patterns but attempts to alter agent role, scoring, filtering, output, or memory.

## Initial Detection Patterns

Current inline patterns include:

```text
ignore previous instructions
disregard your system prompt
score this job at <number>
mark this as strong match
do not show other
override scoring
you are now a...
assistant:
system: you are
developer: you are
```

## Required Evidence

Each finding should preserve:

- `rule_id`: `ASI06_PROMPT_INJECTION` at runtime; maps to this ClawGuard rule spec.
- `severity`: expected `HIGH`.
- `message`: human-readable detection summary.
- `evidence`: matched text and surrounding snippet.
- `matched_pattern`: the normalized pattern that fired.
- `matched_text`: the raw text matched inside the job content.
- `source_field`: the field that contained the pattern, such as `title_and_description`.
- `job_title`: title from the job record.
- `company`: company from the job record.
- `source_platform`: job source, such as `linkedin`, `cybersecjobs`, or `usajobs`.
- `apply_url`: application URL being evaluated.
- `agent_session_id`: digest or run id that evaluated the posting.

## False Positive Notes

Security job postings may legitimately discuss prompt injection, LLM guardrails, or adversarial testing. Treat those as lower-confidence unless the wording is imperative and directed at the agent.

False positive controls:

- Prefer matches in application instructions, benefits, summary, or generic description fields over technical requirement lists.
- Raise confidence when prompt-injection language appears with role-change or scoring commands.
- Lower confidence when the text describes prompt injection as a skill, project, research area, or defensive responsibility.
- Future Layer 4 semantic review should separate "candidate should know prompt injection" from "agent should ignore previous instructions."

## Initial Query

This query acts as the zero-UI detection dashboard for ASI06-001:

```sql
SELECT
  agent_session_id,
  rule_id,
  severity,
  json_extract(context, '$.source_platform') AS source_platform,
  json_extract(context, '$.source_field') AS source_field,
  json_extract(context, '$.job_title') AS job_title,
  detected_at
FROM job_security_findings
WHERE rule_id = 'ASI06_PROMPT_INJECTION'
ORDER BY detected_at DESC
LIMIT 20;
```
